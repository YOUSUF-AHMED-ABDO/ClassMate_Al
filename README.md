# ClassMate AI — University Prototype

## المتطلبات
- Windows 10
- Python 3.10 أو أحدث
- اتصال إنترنت لتثبيت المكتبات أول مرة

## التشغيل على Windows
1. فك ضغط المجلد في مكان عادي مثل سطح المكتب.
2. افتح مجلد `ClassMate_AI`.
3. اكتب `cmd` في شريط عنوان File Explorer واضغط Enter.
4. نفّذ الأوامر التالية سطرًا بسطر:

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

5. افتح `http://localhost:8501` إذا لم يفتح المتصفح تلقائيًا.

إذا لم يعمل الأمر `py`، جرّب استبداله بـ `python`.

## الاستخدام
من القائمة الجانبية افتح «استيراد المحادثة»، ثم ارفع ملف WhatsApp TXT أو حمّل المحادثة التجريبية.

## حدود النسخة الحالية
- استخراج الإعلانات والمهام ورسائل الملفات يعتمد على كلمات مفتاحية.
- البحث نصي محلي.
- لا يوجد تكامل AI API حقيقي حتى الآن.
- لا يوجد اتصال تلقائي أو مباشر بمجموعات WhatsApp.
- تصدير WhatsApp النصي لا يتضمن ملفات الوسائط نفسها عادةً.

هذه نسخة أولية للتجربة والعرض وليست منتجًا نهائيًا.
